# ClassHub UI Design Rules & Clean Full-Screen Auth Template

## Template Đăng Nhập / Đăng Ký (Clean Full-Screen 60/40 Format)

1. **Bố Cục Tràn Màn Hình (Full Screen 100vw x 100vh, Tỷ lệ 60/40)**:
   - **Cột Trái (60% Width, 100vh Height)**:
     - Nền ảnh tốt nghiệp mờ phủ lớp Teal overlay mượt mà.
     - Logo ClassHub thiết kế dạng chữ + icon tinh tế (Icon Mũ cử nhân + Chữ "ClassHub" trắng + Phụ đề "University Student Portal"), KHÔNG dùng khung hộp hình chữ nhật cứng.
     - Dòng slogan: *"Kết nối tri thức – Đồng hành cùng bạn trên hành trình đại học"*.
   - **Cột Phải (40% Width, 100vh Height)**:
     - Nền trắng tinh tế, căn giữa theo chiều dọc.
     - **Icon Phía Trên**: Icon Mũ cử nhân hiển thị trực diện tinh tế, KHÔNG có viền border tròn hay nền filled tròn.
     - **Tiêu Đề**: "Đăng nhập với vai trò" / "Đăng ký tài khoản".
     - **Thanh Chọn Vai Trò (Role Tabs)**: Tab *Sinh viên* & *Giảng viên*. Tab active màu Teal (`#009688` / `bg-[#009688]`).
     - **Form Inputs & Buttons**: Input Tên đăng nhập/Password + Nút Đăng nhập (`#009688`) + Nút Google + Nút Đăng ký tài khoản mới + Link Quên mật khẩu.
     - **LOẠI BỎ**: Phần Dark mode, dòng "Bạn chỉ được phép...", và link bypass.
     - **Chân Trang (Footer)**: Chỉ giữ lại bộ chọn ngôn ngữ (Tiếng Việt / English).
